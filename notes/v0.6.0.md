# S2Arm v0.6.0

## 这一版的重点
- **一个 App，装下所有游戏**：手机上只装一次 S2Arm，所有游戏都在它的游戏库里；以后哪款想玩就在电脑上把哪款「推到 iPhone」。S2Arm 更新、续签都不用重推游戏，存档也都在。装 App、续签、更新在启动器游戏库第一格的「S2Arm」里。0.5 的「每款游戏一个 App」装法已撤掉。
  *One app for every game: install S2Arm on your phone once and every game lives in its library. Whenever you want another game, use Push to iPhone on the computer. Updating or renewing S2Arm never means re-pushing games, and your saves stay. Install, renew and update the app from the S2Arm tile, first in the launcher's game library. The 0.5 one-app-per-game install is gone.*
- **快照：存下这一刻，随时回来**：游戏里点右上角的半透明按钮，此刻的游戏状态整个存下；长按它选「回到上次存下的这一刻」就回去。下次打开游戏库，最上面的「从这一刻继续」点一下直接进。每款只留最新一份，长按可删，设置里可关；快照只在存下它的那台设备上能用。游戏内存里重复的内容只存一份，大小随游戏不同，实测约 0.2–0.5 GB（一款卡牌游戏约 0.2 GB，一款大型格斗游戏约 0.5 GB），存一次的时间也没有变长。
  *Snapshots: tap the translucent button at the top right in game to save the whole game state as it is right now; long-press it and choose to return to the last saved moment. Next time, tap the game under Continue from this moment at the top of the library. One snapshot per game (a new one replaces the old); long-press to delete, or turn it off in settings. A snapshot works only on the device that saved it. Repeated content in game memory is stored only once, and the size varies by game: measured at about 0.2–0.5 GB (about 0.2 GB for a card game, about 0.5 GB for a large fighting game), with no longer save times.*
- **推到 iPhone 快多了**：以前一款大游戏的程序要一个文件一个文件地推（1,500 多个文件约一小时）；现在打成一个 .s2arm 文件一次推过去，手机上的 S2Arm 自己解开换上。实测一款 1,545 个文件的大游戏：打包 6.9 秒，手机解开 6.6 秒。
  *Much faster Push to iPhone: a big game's program used to go over file by file (1,500+ files, about an hour). Now it goes as a single .s2arm file and S2Arm on the phone unpacks it. Measured on a big game with 1,545 files: 6.9 s to pack, 6.6 s to unpack on the phone.*
- **进新场景不再卡一下**：出包时把着色器提前编成苹果显卡的格式。玩家诊断里 69 款游戏在设备上现编失败的着色器共 26,809 个：除去 278 个本身读不成着色器的坏输入，其余 26,531 个现在全部能编出。注意：iPhone 上的预编管线要在电脑连着这台 iPhone「推到 iPhone」时才会生成；导出自签包（不连手机）或同时连着多台 iPhone 时，这一版仍是第一次遇到时现编，和 0.5 一样，后续版本会改进。
  *No more hitch in new scenes: shaders are precompiled for Apple GPUs at build time. Player diagnostics recorded 26,809 shaders across 69 games that failed to compile on device; apart from 278 broken inputs that aren't readable shaders, all 26,531 now compile. Note: on iPhone, precompiled pipelines are generated only when you Push to iPhone with that iPhone connected. When exporting for self-signing (no iPhone connected) or with several iPhones connected, this version still compiles them the first time they are needed, as in 0.5. This will improve in a later version.*

## 新功能
- **.s2arm 文件，换台设备接着玩**：每款游戏可以导出成 .s2arm（配上游戏的 .img），在另一台设备上导入就能玩；第一次开这款时，App 用那台设备自己的签名身份当场签好。
  *.s2arm files: export any game as an .s2arm (with its .img) and import it on another device; the first time it starts, the app signs it with that device's own signing identity.*
- **用 AltStore / SideStore 自签的玩家，手机上就能导入游戏**：① 在 AltStore 或 SideStore 的设置里「导出签名证书」，设一个密码；② 打开 S2Arm，齿轮 →「签名证书」→「导入 .p12…」，选这份证书、输入密码；③ 之后把电脑导出的或朋友分享的 .s2arm 和 .img 放进 S2Arm 的「放这里导入」，就能玩。不用在电脑上登录 Apple ID，也不用新建证书。注意：同一个 Apple ID 只在一台电脑的 AltServer 上管理，两台电脑都用会互相作废证书（AltStore 会弹「Multiple AltServers」）；7 天到期前在 AltStore 点「Refresh All」即可，S2Arm 里不用再做什么。SideStore 用户还可以在第 ② 步点「从 SideStore 获取」一键导入。还没导证书、证书团队对不上、或证书被换掉时，游戏卡片会直接说明原因，并带你去导证书；导好后自动恢复。
  *Self-signing with AltStore / SideStore? Import games right on your phone: ① in AltStore or SideStore settings, export your signing certificate and set a password; ② open S2Arm, gear → Signing certificate → Import .p12…, pick the certificate and enter the password; ③ then put .s2arm and .img files (exported from your computer or shared by a friend) into S2Arm's Import Here folder and play. No Apple ID sign-in on a computer and no new certificate needed. Note: manage each Apple ID from AltServer on only one computer; using two makes them revoke each other's certificates (AltStore shows "Multiple AltServers"). Before the 7 days run out, just tap Refresh All in AltStore; nothing else to do in S2Arm. SideStore users can also tap Get from SideStore in step ②. If no certificate has been imported yet, its team doesn't match, or it has been replaced, the game card says so and takes you to import one; the game comes back by itself once it's imported.*
- **自签玩家也能从电脑直接推游戏**：手机上的 S2Arm 是 AltStore / SideStore 装的，连上电脑后，启动器的总控台会认出来，给出「推所选到 iPhone」「导出所选 .s2arm」「导出 S2Arm.ipa」「把签名身份交给手机」。推过去的游戏由手机上的 S2Arm 用你导入的证书来签，电脑不用登录 Apple ID，也不新建证书。同一台 iPhone 上装着不止一个 S2Arm 时，总控台让你选一个用来推游戏，选一次就记住。
  *Self-signers can push games from the computer too: when S2Arm on your phone was installed by AltStore / SideStore, the launcher's console recognizes it and offers Send selected to iPhone, Export selected as .s2arm, Export S2Arm.ipa and Give the signing identity to the phone. Pushed games are signed on the phone by S2Arm with the certificate you imported, so the computer needs no Apple ID sign-in and creates no new certificate. If one iPhone has more than one S2Arm, the console asks which one to push to and remembers your choice.*
- **Mac 启动器自己登录 Apple ID**：在 Mac 上不再需要 Xcode 账号。设置里「签名身份」下面点「登录 Apple ID」，登录一次即可装 S2Arm、推游戏；登录过期时会直接回到这个登录面板。Xcode 团队只在出包页 Apple TV 那一行还用得到。注意：免费 Apple ID 的证书满了时，在启动器里新建证书会作废你在 AltStore 用的证书，AltStore 和它装的 App 之后会打不开。确认框里点「改用已有证书」导入 .p12，就不用新建。
  *Mac launcher signs in to your Apple ID itself: no Xcode account needed on Mac anymore. In Settings, under Signing identity, click Sign In with Apple ID once to install S2Arm and push games; when the sign-in expires you land straight back in this panel. The Xcode team is now only used on the build page's Apple TV row. Note: when a free Apple ID's certificates are full, creating a new certificate in the launcher revokes the certificate you use in AltStore, and AltStore and the apps it installed will stop opening afterwards. Click Use an existing certificate in the confirmation to import a .p12 instead of creating one.*
- **联机模式（社区贡献，#1075，感谢 SyunSS）**：iPhone 和 Mac 设置里新增「联机模式」：「自动」照旧在局域网里互相发现；「指定 IP」让一台设备托管中继，其他玩家填写这台设备的 IPv4 地址联机。跨网络需要自备能互通的网络（例如 VPN），S2Arm 不内置 VPN。
  *Multiplayer mode (community contribution, #1075, thanks SyunSS): iPhone and Mac settings add Multiplayer mode. Automatic keeps LAN discovery as before; Manual IP lets one device host a relay while other players enter that device's IPv4 address. Across networks, bring your own reachable network such as a VPN; S2Arm doesn't include one.*
- **手柄**：Mac 上的任天堂手柄（Switch Pro、Joy-Con 等）可以改成 Xbox 位置布局（下键确认、右键取消），和 iPhone 一致；iPhone 接没有陀螺仪或马达的外接手柄时，体感自动改用手机陀螺仪，震动改用手机马达。
  *Controllers: on Mac, Nintendo controllers (Switch Pro, Joy-Con and others) can now use the Xbox button layout (bottom to confirm, right to cancel), matching iPhone. On iPhone, controllers without a gyroscope or rumble motor now fall back to the phone's gyroscope for motion and to the phone's motor for rumble.*
- **游戏内报修按钮**：iPhone 游戏里，左上角齿轮右边多了一颗报修按钮，点了直接进报修框。iPhone、Mac、Windows 三端报修时描述改为必填，写清哪款游戏、做了什么、看到了什么就行。
  *In-game report button: on iPhone, a report button now sits right of the gear at the top left and opens the report form directly. On iPhone, Mac and Windows a description is now required: which game, what you did, what you saw.*
- **开局更快**：去掉了每次启动游戏前的文件校验。文件真坏了，会照实报启动失败和原因。
  *Games start faster: the file checks before every start are gone. If a file really is broken, the start fails and says why.*
- **每款游戏占多少一眼看清**：每款游戏的「…」菜单里「释放空间」分项列出着色器与出包缓存、Mac 运行版本、已出好的 iPhone 包各占多少，勾上不要的点「释放」；存档和日志只显示大小、不会被删。
  *See what each game takes: Free up space in each game's "…" menu lists shader and build caches, the Mac version and built iPhone packages separately; tick what you don't need and click Free. Saves and logs are shown but never deleted.*
- **快照恢复失败时会说**：回到某一刻没成功、从头开局时，弹一句「没能回到那一刻」和原因，不再悄悄退回。
  *If returning to a snapshot fails and the game starts fresh, you're told why instead of it silently falling back.*
- **Apple TV 也是一个 App（实验）**：Apple TV 改成和 iPhone 一样，S2Arm 只装一次，各款游戏按 Apple TV 签好推进去。目前只有 Mac 启动器走这种一个 App 的装法，Windows 启动器仍是导出 Apple TV 安装包、用你自己的签名工具签名后装到电视。这条还在真机上复测，请先当实验功能用。
  *Apple TV, one app too (experimental): S2Arm is installed once and each game is signed for Apple TV and pushed in. For now only the Mac launcher installs this one-app way; the Windows launcher still exports an Apple TV package for you to sign with your own signing tool and install on the TV. Still being re-tested on real hardware, so treat it as experimental.*

## 修复
- **Windows：添加游戏后选中的是刚加的那款**，不再跳回上一款的出包页。
  *Windows: after adding a game, the new game is selected instead of jumping back to the previous game's build page.*
- **Windows：一款在出包时打开另一款，进的是那款自己的出包页**，可以「加入出包队列」排在后面，前一款出完自动开始。
  *Windows: while one game is building, opening another goes to that game's own build page, where you can add it to the build queue; it starts automatically when the current build finishes.*
- **Mac：一代 Joy-Con 的体感**：关了「震动」或没有能震动的手柄时体感整局没打开；游戏的手柄设置画面把「一对 Joy-Con」误判成不符合要求。两处都已修好，手上没有一代 Joy-Con，按修复推断，待玩家确认。（#1671）
  *Mac: motion on original Joy-Con. Motion stayed off for the whole session when rumble was disabled or no rumble-capable controller was connected, and the game's controller setup screen wrongly rejected a Joy-Con pair. Both fixed; we have no original Joy-Con to test with, so this awaits player confirmation. (#1671)*
- **Trine 5（Mac）：进入游戏后花屏**已修好（同一个包在 Mac 上前后对照，相关报错从 8 行降到 0）。（#1468）
  *Trine 5 (Mac): fixed graphical corruption after entering the game (same package compared on Mac before and after: the related error lines went from 8 to 0). (#1468)*
- **Mac / iPhone：用到超大内存池的部分游戏，GPU 计算类效果缺失或冻住、部分物体闪烁或消失**，已修好（不崩溃；Windows 版不受影响）。按修复推断，尚未在这些游戏上实测，待玩家确认。
  *Mac / iPhone: in some games that use very large memory pools, GPU compute effects could be missing or frozen and some objects could flicker or disappear (no crashes; Windows was not affected). Fixed; this is inferred from the fix and not yet tested on those games, so it awaits player confirmation.*
- **快照回到这一刻后画面全黑**（一款大作上出现过）已修好，Mac 上已验证。
  *Fixed a black screen after returning to a snapshot, seen on one big game; verified on Mac.*
- **开了 60 帧却一直是 30 帧**：以前一局掉过帧，之后每局都被压在 30 帧，看起来像 60 帧开关没用。现在每局都从 60 帧开始；一局里跑不稳会先回到原生帧率，并弹横幅说明原因，带「再试 60 帧」按钮，Mac 上也有这条提示了；局中重新打开 60 帧开关同样回到 60 帧。（#1688）
  *60 FPS turned on but stuck at 30: after one session dropped frames, every later session used to stay at 30 FPS, so the 60 FPS switch looked broken. Every session now starts at 60 FPS; if a session can't hold it, the game drops back to its native frame rate with a banner explaining why and a Try 60 FPS again button, now on Mac too. Turning the 60 FPS switch back on mid-session also returns to 60. (#1688)*
- **Mac：一款开放世界大作战斗中卡死、画面碎开**：图形命令列表互相调用成环时，原先会一层层嵌到上限、把同一批命令在显卡上重复跑，单帧卡 3 秒。现在第一次成环就跳过。按修复推断，待玩家确认。（#1728）
  *Mac: an open-world game froze mid-battle and the picture broke into pieces. When graphics command lists called each other in a loop, they used to nest up to the limit and run the same commands on the GPU again and again, stalling a frame for 3 seconds. The loop is now skipped the first time. Inferred from the fix; awaits player confirmation. (#1728)*
- **Mac：游戏库在外接盘时出包写满内置盘**：追加内容（DLC）的解包缓存改为放在这款游戏自己的文件夹里；真写满时，报错会写清是哪块盘、这一步要多少、还差多少。（#1725）
  *Mac: building wrote the internal disk full when the library was on an external disk. The DLC unpack cache now lives in the game's own folder, and if a disk really fills up, the error names the disk, how much the step needs and how much is missing. (#1725)*
- **只在 Mac 上玩的游戏，被提示「要更新手机版本」**，已修好。（#1712）
  *Games played only on Mac no longer get an "update the phone version" hint. (#1712)*
- **把游戏库搬到 exFAT 等非 APFS 的盘时失败**，已修好。（#1720）
  *Moving the game library to an exFAT or other non-APFS disk no longer fails. (#1720)*
- **Windows：出包时目录正被杀毒软件或索引程序占用**，不再整单报「文件或目录不可访问」，会等它扫完再继续。
  *Windows: when antivirus or indexing software is holding a folder during a build, the build now waits for it instead of failing with "file or folder not accessible".*

## 从 0.5 升级
你手机上原来的游戏、存档和游戏数据都会留着，不用重新出包，也不用重传游戏数据。
*The games, saves and game data already on your phone all stay. No rebuilding, no re-uploading game data.*
1. Mac 玩家先在 S2Arm 里用 Apple ID 登录一次。
   *On Mac, sign in with your Apple ID once inside S2Arm.*
2. 连上手机，在游戏库第一格的「S2Arm」里点「更新 S2Arm」：先把各款存档备份到电脑，再换成新 App。
   *Connect the phone and click Update S2Arm on the S2Arm tile. Saves are backed up to the computer first, then the new app goes on.*
3. 装完同一页会列出这台手机上要更新的旧游戏，默认全勾，点「更新这 N 款」，每款约 1–2 分钟。旧版做的着色器库电脑会顺带按新版重做，第一次要几分钟到几十分钟。不用点 S 级优化。
   *The same page lists the old games on this phone, all ticked; click Update these N games, about 1–2 minutes each. Shader libraries made by the old version are rebuilt along the way, taking minutes to tens of minutes the first time. No need to run S-grade optimization.*

第 3 步做完之前，这些游戏在手机上显示「需要导入一次 .s2arm」，存档和数据都在：点它直接选这款的 .s2arm 导入。别的电脑装的另起一行列出，到那台电脑上更新。用 AltStore 等自己签名的：连上手机，在游戏库第一格「S2Arm」里点「安装 S2Arm」，在提示还没登录 Apple ID 的那一页点「改为导出自签包（不用连手机）」，得到新版 S2Arm.ipa，用 AltStore 装上覆盖旧的；再导入签名证书（SideStore 在 S2Arm 里点「从 SideStore 获取」，AltStore 导出后点「导入 .p12…」）；最后在总控台点「推所选到 iPhone」，或对每款点「导出自签包」，把 .s2arm 和 .img 放进「放这里导入」。
*Until step 3 is done, those games show "Needs its .s2arm once" on the phone, and saves and data are all still there: tap it to pick this game's .s2arm and import it. Games installed from another computer are listed separately; update them there. If you self-sign with AltStore or similar: connect the phone, click Install S2Arm on the S2Arm card first in the library, and on the page saying you aren't signed in with an Apple ID, click Export for self-signing instead (no iPhone needed) to get the new S2Arm.ipa; install it over the old one with AltStore; import your signing certificate (SideStore: Get from SideStore in S2Arm; AltStore: export it, then Import .p12…); finally click Send selected to iPhone in the console, or click Export for self-signing on each game and put its .s2arm and .img into Import Here.*
